Vấn đề

Database của bạn là một kho PII.

HTTPS bảo vệ lúc truyền. Nhưng DB dump, backup bị trộm, read replica hay SQL injection vẫn làm lộ email khách hàng và dữ liệu user khi lưu — trừ khi chính các field được mã hoá.

Laravel mặc định

Email nằm plaintext

Bảng users, password reset, backup và export đều có thể chứa email đọc được.

Chỉ hash

Login và unique bị hỏng

Hash một chiều bảo vệ giá trị nhưng bạn vẫn cần login không phân biệt hoa thường, reset lookup và chống trùng.

Tự làm crypto

Migrate và rotate nguy hiểm

Tự quản lý key dễ sai khi migrate dữ liệu cũ, rotate key và rollback.

Bạn nhận được gì

Một package Laravel nhỏ, không phải viết lại app.

Khi lưu

DB dump không đọc được PII

Field đã khai báo lưu dạng enc:v1:…; key nằm trong env hoặc secret manager.

Không rewrite

Eloquent vẫn dễ đọc

$user->email, getAttribute(), notification và mail vẫn nhận plaintext.

Auth nguyên vẹn

Login và reset hoạt động

Auth::attempt(), reset mật khẩu và notification dùng email đã mã hoá an toàn.

Lookup

Tìm email bằng blind index

Exact lookup không phân biệt hoa thường qua email_bidx, kèm unique index cho đăng ký.

Vận hành

Backfill và rotate key

Mã hoá dữ liệu cũ, điền index còn thiếu và rotate key bằng Artisan command có dry-run.

Open source

Source, changelog, release trên GitHub. Không admin UI, không giữ key hộ; key thuộc về bạn.

Cách hoạt động

Default deny: chỉ field khai báo trong config mới bị mã hoá. Không patch core, không ép đổi framework.

▦

Một config map

Khai báo tối đa 20 field mỗi model, kèm index và normalize tùy chọn.

🔐

AES-256-GCM

Mã hoá có xác thực, randomized; mỗi payload lưu key id để rotate key.

🔎

Blind index

HMAC-SHA256 của giá trị đã normalize và tên field; exact lookup không lưu plaintext trong index.

👤

Login email

Custom user provider map credential email sang blind index của email đã mã hoá.

🔁

Reset mật khẩu

Driver broker encrypted-database lưu blind index vào bảng reset token.

🧰

Vận hành

Status, backfill có dry-run, rotate key, chunk tùy chỉnh và publish migration.

Cài đặt

Yêu cầu PHP 8.1+, Laravel 10/11/12 và OpenSSL. Backup DB trước khi mã hoá dữ liệu cũ.

01

Thêm package qua GitHub VCS, publish config/migration.

02

Đặt key ring, token secret và map field cho model.

03

Backfill, đổi auth/password driver rồi test login.

FAQ

Câu hỏi trước khi mua

Có mã hoá luôn cột email không?

Có. Email lưu dạng ciphertext AES-256-GCM; cột email_bidx riêng lưu HMAC đã normalize để exact lookup và unique.

User vẫn login và reset mật khẩu được không?

Được. Custom user provider map credential login sang email_bidx, và password broker mã hoá giữ token reset không chứa email plaintext.

Có tìm một phần email được không?

Không. Blind index chỉ hỗ trợ exact equality. Tìm LIKE một phần cần token index riêng, ngoài phạm vi package.

Validate unique email thế nào?

Dùng EncryptedUnique(User::class, 'email') thay vì unique:users,email, vì email lưu trong DB là ciphertext.

Mất key thì sao?

Không thể khôi phục giá trị đã mã hoá nếu mất key. Hãy backup key ring ngoài DB và diễn tập rotation trước khi đổi key.

Có dùng cho dưới 20 field không?

Có. Thêm bao nhiêu field cũng được vào map model. Field có index sẽ tìm kiếm được; field không có index chỉ mã hoá.

Có miễn phí không?

Có. GPL-2.0-or-later, source và release trên GitHub. Không có bản trả phí, telemetry hay key escrow.
